## 原来 7 项失败的核实结果

| 项目 | 核实原因 | 处理 |
| --- | --- | --- |
| 授权上下文 | 测试 Session 缺少 `navigator_language()`，被实现的异常兜底捕获，返回原 URL | 补全测试会话，并断言语言参数 |
| 两项 IMAP/2FA 测试 | 模拟重定向未返回验证页 URL，且旧断言仍要求首次主动发码/重发 | 使用真实形状的验证页 URL；断言不首次重发、取码终止后不重新启动认证 |
| 促销字段保存 | 测试替换了不再被使用的全量加载/保存函数；真实实现已使用按记录 SQLite 读写 | 改为临时 SQLite，验证实际保存、轮询版本变化和失败时保留历史权益；不接触正式库 |
| authorize 重试 | 测试只 mock `time.sleep`，单调时钟不前进，分段等待函数空转并积累大量 mock 调用 | 在重试调度边界 mock `_interruptible_sleep`，固定本测试退避参数 |
| 时区 | Windows 环境未安装 IANA 时区数据库，`Asia/Bangkok` 解析失败，静默回退到东京偏移 540 而非 420 | 声明并安装 `tzdata` 依赖；原时区测试通过 |
| Cloudflare 并发 | 旧测试把请求里的 `workers=1` 当作实际并发，但页面保存的并发值才是当前契约 | 隔离测试保存值为 1，不依赖用户 `.env`；保留保存按钮决定并发的业务规则 |

这些问题不能统一称为环境问题：时区依赖缺失会影响实际运行，其他项目主要是测试夹具/契约未同步。

## 额外修复的实际缺陷

1. **外来 Session 污染凭据**：`apply_session_fields` 拒绝不匹配邮箱的 Session JSON，但查活写回仍继续覆盖 Token/用户资料。现在在任何写回前拒绝明确的邮箱不匹配，保持原记录不变。
2. **密码/SESSION 按钮轮询不更新**：补齐密码存在标记和设置状态；将密码及 Session 存在标记纳入轮询 revision，覆盖同一秒内的状态变化。接口不返回密码、Session JSON 或 Cookie 正文。
3. **非法 JSON 引发 500 或误用默认值**：API 写请求的 JSON 非对象/解析失败时统一返回 400，位于鉴权之后、驱动检查和任务派发之前，不回显请求内容。
4. **凭据日志**：移除 2FA enrollment/activation 错误正文和部分响应字典的回显；L/H/Grizzly 短信成功日志不再打印验证码。
5. **测试数据隔离**：新增 `tools/run_offline_tests.py`，将源文件复制到临时目录，生成不含凭据的协议测试配置，不复制正式数据库、`.env` 或根目录抓包。Python 测试对常用 HTTP 客户端的外网请求和非回环 socket 连接设防；不会运行真实注册稳定性脚本。
